XPath Helper (MV3) 2.1.0 — 基于 XPath Helper 2.0.2 的非官方适配版

1. 将下载的 ZIP 解压到准备长期保留的位置。
2. 在 Chrome 打开 chrome://extensions，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含 manifest.json 的目录。
4. 刷新网页，点击扩展图标或按 Ctrl+Shift+X 打开面板。
5. 按住 Shift，将鼠标移动到网页元素上生成 XPath；也可在 Query 直接输入。

macOS 对应快捷键为 Command+Shift+X。
安装后保留目录。更新时覆盖原加载目录的文件，再重新加载扩展并刷新网页。
不要通过卸载来更新，否则会清除本地历史与收藏。
Chrome 内置页面和商店等受保护页面无法使用。
本发布提供 ZIP 供解压加载；自行打包的 CRX 可能被 Chrome 来源验证禁用。

新功能
- 智能相对 XPath / 绝对 XPath 切换；处理属性引号和 SVG 定位。
- 复制 XPath、复制结果；显示唯一匹配、多项、未匹配或错误。
- 运行（Ctrl/Command+Enter）或成功复制 XPath 时记入历史。
- 输入名称后收藏，通过“历史与收藏”恢复、删除或清空当前网站的记录。
- 按住 Shift 并移动到面板标题，可以上下移动面板。

记录使用新增的 storage 权限保存在本机，不云同步、不保存匹配结果。
每站点历史30条、收藏50条；表达式本身可能包含页面文字，请按需清理。
所有本地文件共用一个分类；隐身窗口不读取或保存历史与收藏。
自动化检查范围及已知限制见 README.md；macOS 尚未做实机验证。
