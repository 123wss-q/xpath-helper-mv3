additional strict-mode directives in JavaScript and a store update URL in the manifest.

Modified on 2026-11-02:
- manifest.json: Manifest V3, service worker, action, resource declarations;
  updated version/name and unofficial adaptation description; removed the original
  store update URL.
- background.js: service worker-compatible action and validated panel-command routing.
- content.js: initialize an empty query and refresh after the panel-ready handshake.
- bar.js: scope updates to the containing tab, signal readiness, and use input events.
- Replaced the original icons with new geometric artwork in static/ and assets/.
- Added public installation, attribution and release documentation, and routing checks.
- Removed obsolete background HTML, original signature metadata and unused build,
  font and promotional files.
